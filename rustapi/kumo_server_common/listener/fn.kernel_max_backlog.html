pub fn kernel_max_backlog() -> u32
Expand description

Returns the kernel’s maximum accept-queue length, which is the largest backlog listen(2) will honor. A larger request is silently clamped down to this value. On Linux this is net.core.somaxconn. Elsewhere, and when it cannot be read, returns a conservative default that the kernel will clamp down further if needed.
