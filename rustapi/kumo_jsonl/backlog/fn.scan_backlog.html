pub fn scan_backlog(
    directory: &Utf8Path,
    pattern: &str,
) -> Result<Vec<ConsumerBacklog>>
Expand description

Scan directory and report the backlog of each consumer relative to the newest segment matching pattern. Consumers are discovered by their .<checkpoint_name> files. Segment contents are never decompressed. Only their directory listing and file metadata are read. A nonexistent directory yields an empty report.
